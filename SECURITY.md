# Security Policy

## Supported versions

Security fixes are initially targeted at the latest published release and the default branch. Older DMG builds may not receive updates.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public GitHub issue. Use GitHub’s private vulnerability reporting feature for this repository when available. If that feature is not available, contact the repository maintainer through the contact method listed in the GitHub profile and include the minimum information needed to reproduce the issue.

Do not include private prose, personal documents, API keys, signing credentials, or other sensitive content in a report.

## Security boundaries

StopSlop is intended to operate locally and does not require a cloud service for core analysis. Reports involving unexpected network access, raw-text persistence, unsafe command execution, missing upstream notices, or package tampering should be treated as high priority.

The project does not guarantee that the detector’s score is suitable for authorship, academic, employment, legal, disciplinary, or other high-stakes decisions. Security reports and product feedback should keep this limitation in view.
